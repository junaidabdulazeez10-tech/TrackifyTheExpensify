# TrackifyTheExpensify

A full-stack personal finance application for tracking income, expenses, and monthly budgets.

TrackifyTheExpensify provides users with a personalized dashboard for monitoring their finances, visualizing spending patterns, managing category-based budgets, and reviewing transaction history.

## Features

- Secure email and password authentication
- User-specific transactions and budgets
- Income and expense tracking
- Monthly income, expenses, balance, and savings calculations
- Income vs. expense visualization by month
- Expense breakdown by category
- Monthly and category-based budget management
- Budget progress and remaining-budget calculations
- Transaction filtering
- Recent transaction overview
- Responsive layout for desktop and mobile devices
- Dark and light themes with animated backgrounds
- Demo page for exploring the application
- Unit tests for financial calculation logic
